# LinkedIn post: recall

Most people use AI agents for coding. I run infrastructure, so mine spends its day on root cause analysis, troubleshooting, fixes and deployments, and for that it needs more than a good model: it needs my notes, a safe way to authenticate and a map of my systems.

I built a small tool so the agent can find my notes, authenticate without ever seeing a credential, and know how to reach the systems I work with. Before it, every session started with me explaining the same things and setting up access manually. Now the agent looks them up itself, and the difference in its answers is real. I wrote up the design, with diagrams and short terminal recordings, here:

https://vigneshragupathy.com/recall-how-my-ai-agent-finds-authenticates-and-connects/
